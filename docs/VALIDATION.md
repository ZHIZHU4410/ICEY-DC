## 已处理的失败与替代

1. 1.0.1高清更新曾长时间持有邮箱锁，使DC连续present却重复显示旧ICEY帧；转换/统计已移到锁外，原生日志只读帧头。
2. StreamReader预读下一行后，socket Available为0导致输入等到下一包，曾出现约187–399ms消费延迟；改用直接字节接收与增量分行，并用两个合并消息及分片消息验证。
3. 重复调用LightedLayers.sync清空延迟灯光/FX队列，而子对象因lastFrame相同跳过；移除重复sync。用户后续指出的雾膜是独立问题。
4. 15:19:22的临时no-depth-fog切换后出现“Can't cast f64 to h3d.Vector”。当时源码/DLL/日志已归档；发布代码彻底移除该分支，采用只改变CamFog可见性的替代。最终关卡绘制与回血验证无同期Fatal，未宣称所有渲染场景永不崩溃。
5. 菜单默认选中退出与DPI虚拟坐标曾导致正常退出，前台防护停止继续发键；通过截图和物理坐标纠正。没有把已退出进程认作脚本正常关闭。
6. 多次启动的空日志曾被汇总脚本误选，得到0输入；原错误结果保留，按QPC窗口读取全部启动日志后得到48条，更正数据单独保存。

这些修复仍服务同一目标：DC世界中的原生ICEY逻辑与真实当前帧。未使用换皮、固定诊断位置、A1图集或外部透明窗口作为成功兜底。
