# v1.0.9 全视野蓄力斩击

原生 Charge1End、QTECharge1End、AirChargeEnd 释放时发送独立 CHARGE 事件；主端按当前摄像机视野矩形选择所有存活 Mob（包括边缘部分可见者），使用原生蓄力伤害，不进行视线或墙体检查。按场景代次和原生 attackId 去重，替代该斩击的局部碰撞伤害上报，避免重复结算。怪物自身防御/无敌规则仍由原生战斗处理。

原生 ChargingScreenEffect 动画通过单独512×256透明画面、30Hz导出并铺满屏幕，不改变角色或世界比例；排除 Black/White 不透明底板，主角色捕获中排除同组特效避免双绘。切换角色、场景变化和超过1/3秒无帧时隐藏覆盖层。仅实时捕获用户运行的原生特效，无提取/分发素材。

继承旧版原地回血、冲刺通道和破门、梯子交接比例修复、去雾以及启动残留自动清理。
