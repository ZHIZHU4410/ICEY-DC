手测顺序：先结束旧会话，再运行本候选 Run-Playtest.cmd。前台 DC 按 F7 选 ICEY。先拍同一关的 ICEY/原 Hero 光照对比；再找恰好一格高实墙按 O，确认跨过并落在墙顶，接着试两格高墙和头顶阻挡。普通怪物打到约 30% 血量，靠近确认头顶 L；按 L 观察原生处决动画、生命回复、DC 怪物死亡和现场晶体；晶体存在时长按 J 蓄力，晶体消失后再次尝试长按 J。每项均需结合 combat_guest.csv、combat_host.csv、world_mirror.csv 与游戏画面判定。
